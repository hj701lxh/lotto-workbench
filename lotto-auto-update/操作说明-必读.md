# 彩票工作台 · 数据自动更新 部署说明

> 目标：让双色球 / 大乐透数据**每期开奖后自动更新**，无需你手动干预。

---

## 一、原理（30 秒看懂）

```
GitHub 定时任务（每天 4 次）
   ↓
自动抓取 500彩票网最新开奖
   ↓
自动更新仓库里的 snapshot.js
   ↓
GitHub Pages 自动重新部署
   ↓
你打开网站 → 就是最新一期 ✅
```

**关键：你上传完这 4 个文件，以后什么都不用做了。**

---

## 二、要上传的 4 个文件

解压 `lotto-auto-update.zip`，里面结构如下（**必须保持这个目录结构**）：

```
lotto-auto-update/
├── .github/
│   └── workflows/
│       └── update-snapshots.yml      ← 定时任务配置
├── tools/
│   └── update_snapshots.mjs          ← 抓取脚本
├── ssq/
│   └── snapshot.js                   ← 双色球最新数据（3501 期）
└── dlt/
    └── snapshot.js                   ← 大乐透最新数据（2921 期）
```

⚠️ **两个「已存在」的文件会被覆盖**：
- `ssq/snapshot.js` → 覆盖仓库里旧的
- `dlt/snapshot.js` → 覆盖仓库里旧的

⚠️ **两个「新增」的**：
- `.github/workflows/update-snapshots.yml`
- `tools/update_snapshots.mjs`

## 三、上传步骤（电脑网页操作，约 3 分钟）

### 第 1 步：进入仓库并上传

1. 打开 `https://github.com/hj7011xh/lotto-workbench`
2. 点右上角 **「Add file」→「Upload files」**
3. 把解压后的 **`lotto-auto-update` 文件夹里的内容**（`.github`、`tools`、`ssq`、`dlt` 四个文件夹）**整体拖进去**

> 💡 拖拽时请拖**这四个文件夹本身**，而不是里面的文件——GitHub 支持保留目录结构上传。

### 第 2 步：提交

1. 滚到页面底部
2. Commit message 保持默认即可
3. 点绿色 **「Commit changes」**

### 第 3 步：确认覆盖成功

提交后回到仓库首页，检查：
- ✅ `ssq/snapshot.js` 的提交时间变成了「刚刚」
- ✅ `dlt/snapshot.js` 也是「刚刚」
- ✅ 出现了 `.github` 文件夹（**注意：GitHub 默认可能不显示点开头的隐藏文件夹**）

### 第 4 步：开启 Actions（重要！）

1. 点仓库顶部 **「Actions」** 标签
2. 首次进入会提示：
   > **Workflows aren't being run on this repository**
   或
   > **I understand my workflows, go ahead and enable them**

   点绿色 **「I understand my workflows, go ahead and enable them」** 按钮

> 这一步必须做，否则定时任务不会启动。

### 第 5 步：手动跑一次验证

1. 在 Actions 页面，左侧点 **「Auto Update Lotto Snapshots」**
2. 右侧点 **「Run workflow」** 下拉 → 点绿色 **「Run workflow」**
3. 等约 30 秒刷新页面，应看到一条**绿色 ✓** 的运行记录
4. 点进去看日志，应该能看到：
   ```
   [ssq] ⏭  无新开奖数据（最新仍为 2026104），文件保持不变
   [dlt] ⏭  无新开奖数据（最新仍为 26103），文件保持不变
   ```
   > 说明脚本连通、抓取正常、且智能跳过了无变化的情况 ✅

## 五、常见问题

**Q：怎么知道自动更新真的在跑？**
A：点仓库「Actions」标签，能看到每天 4 条运行记录（绿色 ✓）。有新数据时会多一条 `chore: 自动更新开奖数据 ...` 的提交。

**Q：会不会产生一堆没用的提交？**
A：不会。脚本有幂等保护——**没有新开奖时文件一个字都不改**，不会提交。

**Q：500 彩票网改版了怎么办？**
A：脚本会在日志里报错，快照文件保持原样不动（网站不会坏）。这时候把 Actions 的报错日志截图发我，我来修。

**Q：数据多久生效？**
A：开奖后约 40 分钟内（22:00 那次抓取）网站就是最新数据。极端情况下官网延迟出数据，23:30 那次会补上。

**Q：以后还需要找你更新吗？**
A：不需要了。这套机制是**永久自动**的。
